---
name: equall-governance
description: Use when the user wants to find an Equall data room or ask about a published Equall governance report.
---

Use the tools exposed by the Equall connection. Find the room through the room listing if its identity is unknown. If several rooms could match, ask the user to choose the room before retrieving its governance data. If the server offers a section selector, use it for questions about just one section.

Support claims with the source citations and report links returned by Equall. Distinguish missing or unavailable information from a finding that a right or approval requirement does not exist. If Equall reports that the room is inaccessible or its report is unpublished, relay the limitation. If sign-in is required, direct the user to the plugin's connection flow.
